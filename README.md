# Palma Agent

AI assistants for entrepreneurs, artists, and creators.

## What is Palma Agent?

Palma Agent is a platform of AI assistants designed to help entrepreneurs, artists, and creators automate tasks, develop ideas, and manage their digital presence — without needing technical expertise.

## The Assistants

### Lemuel
A strategic assistant that helps develop ideas, make decisions, and detect when procrastination or emotional blocks are stalling a project.

### Max
A task executor. The user asks, Max delivers: documents, emails, stock management, customer service, automations.

### Mía
A marketing and social media assistant. Content strategy, publications, visual design, calendars. Over 100 dedicated tools.

## Current Status

- 1 active user since August 2026
- 10-20 beta testers at €17/month
- Running 24/7 on a VPS in Europe
- Built over 10 months using open source frameworks

## Stack

- [Hermes Agent](https://github.com/hermes-agent) — open source agent framework
- [OpenCode](https://github.com/opencode-ai) — open source AI coding assistant
- Hetzner VPS — European infrastructure, GDPR compliant

## Mission

We believe intelligent automation should not be a privilege of large companies. Palma Agent provides accessible AI assistants to entrepreneurs and creators who lack the technical resources or time to implement complex automation systems.

## Financial Transparency

All expenses and income are managed through [Open Collective Europe](https://opencollective.com/europe) with a public ledger.
